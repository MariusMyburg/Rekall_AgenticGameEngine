# Rekall AGE Privacy Policy

Effective date: 30 August 2026

Rekall AGE is a Windows game-authoring application developed and published by Rekall. This policy describes how the Early Access version handles information.

## Local-first operation

Rekall AGE does not include automatic product analytics or automatic telemetry upload. Projects, prompts, transaction history, diagnostics, crash reports, captures, provider configuration, and generated content are stored on the user's computer unless the user deliberately sends or publishes them elsewhere.

Steam may process purchase, account, download, playtime, community, and support information under Valve's own privacy policy. Rekall AGE does not receive a user's Steam password or payment-card details.

## Language-model and asset providers

Rekall AGE can connect to local software such as Ollama and to optional third-party language-model or asset services selected and configured by the user.

When a user invokes a cloud provider, Rekall AGE sends the request and the bounded project context needed for that operation to the selected provider. Depending on the requested task, that context can contain prompts, project and scene data, source code, diagnostics, asset metadata, or other user-selected content. The provider processes that information under its own terms and privacy policy. Provider accounts, API charges, retention, and training practices are controlled by that provider, not Rekall AGE.

Local-model operation remains on the user's computer except for model downloads or other network activity performed by the local model host itself.

## Credentials

Provider credentials are read from user-controlled local configuration or environment sources. Rekall AGE is designed not to place credentials in projects, diagnostics, crash reports, evidence archives, or packaged games. Users should still review material before sharing a project or diagnostic bundle.

## User-created content

Rekall AGE does not automatically upload authored games or assets to Rekall. Users control where they save, copy, publish, or share their projects and packaged games. A project may contain personal information that its author entered; deleting that project or information is under the user's local file control.

## Retention and deletion

Because Rekall AGE's own authoring data is local, users can retain or delete it through Studio and normal Windows file management. Uninstalling Rekall AGE does not intentionally delete user projects. Third-party providers and Steam apply their own retention and deletion procedures to information they process.

## Children

Rekall AGE is professional game-development software and is not directed to children. Users must meet the age requirements of Steam and any optional provider they connect.

## Security and changes

No software can guarantee absolute security. Keep provider credentials private, review generated code and assets, and install updates through trusted channels. This policy may be updated as Early Access features change; the effective date and public revision history identify changes.
