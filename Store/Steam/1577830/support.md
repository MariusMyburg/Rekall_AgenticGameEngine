# Rekall AGE Support

Rekall AGE is an Early Access developer preview. Support and reproducible bug reports are handled through:

- Support website: https://rekall-ai.com
- Steam Discussions for app 1577830 after the community hub is enabled

## Before filing a report

Check Help → Documentation in Studio and include:

- Rekall AGE version and Steam build ID
- Windows version
- GPU model and graphics-driver version
- project and scene name, using a reduced project if the original is private
- Studio workspace and operation being used
- provider and model name, without credentials
- the first displayed error and approximate time
- exact reproduction steps
- relevant local diagnostics, after reviewing them for private content

Never post API keys, Steam credentials, private source code, or licensed assets you cannot redistribute.

## Priority

Purchase, installation, launch, data-loss, security, and unexpected provider-billing problems should be labeled clearly. Feature requests should explain the game-authoring outcome that is currently blocked so the underlying generic engine contract can be evaluated.
